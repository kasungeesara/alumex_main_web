# Alumex PLC – Official Website

The official corporate website of **Alumex PLC**, rebuilt from the ground up
to replace the existing site with a faster, more accessible, and easier-to-maintain
platform.

## Overview

This project modernizes Alumex's web presence, presenting the company, its
products, and its services through a clean, responsive experience across all
devices.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** _to be decided_

## Standards & Practices

- **Performance:** Core Web Vitals-focused (image optimization, code splitting, SSG/ISR where suitable)
- **SEO:** Semantic HTML, metadata API, sitemap, robots.txt, structured data
- **Accessibility:** WCAG 2.1 AA guidelines
- **Responsive:** Mobile-first design
- **Security:** Secure headers, environment-based secrets, dependency auditing
- **Code quality:** ESLint, Prettier, conventional commits, PR-based workflow

## Getting Started

    git clone <repository-url>
    cd <repository-name>
    npm install
    npm run dev

Open http://localhost:3000 in your browser.

## Environment Variables

Copy `.env.example` to `.env.local` and fill in the required values.
