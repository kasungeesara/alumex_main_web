## Overview

The smaller components of an aluminium system have a direct impact on everyday use. Handles, rollers, hinges, locking mechanisms and fixing accessories need to work together with the profile and opening configuration.

Alumex hardware enquiries focus on system compatibility and the way each component will be used. Whether completing a new installation or discussing replacement parts, provide profile details and photographs so the correct accessory can be identified.

## Specifications

### System Compatibility

- Hardware selection should match the specific aluminium profile and opening type.
- Review dimensions, fixing positions and interfaces before specifying components.
- For replacements, share photographs and identifying details of the existing installation.

### Operation & Handling

- Discuss handle, roller, hinge and locking requirements for the intended application.
- Select components with reference to panel size, operating conditions and usage.
- Check adjustment and maintenance needs with the installation team.

### Specification & Care

- Confirm availability, compatible finishes and component details before ordering.
- Follow the relevant installation and maintenance guidance for the selected accessory.
- Load ratings, security properties and corrosion performance must be verified for each specified component.

## Benefits

- Complete an aluminium installation with compatible accessories.
- Coordinate appearance and operation across windows and doors.
- Make replacement enquiries easier with clear component identification.
- Plan access for adjustment, cleaning and maintenance.
- Discuss hardware for residential, commercial and project-based applications.
- Reduce selection uncertainty by reviewing the profile and hardware together.
